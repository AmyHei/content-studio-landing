每周一更新的 niche 雷达。我每周扫 HackerNews 前 50 + 百度实时热搜 + pytrends 跨 12 领域英文种子词 + Reddit OAuth + Google/百度 autocomplete + 跨领域 WebSearch,用「不预设方向」的种子词**搜索整理**出本周值得加进 SEO 候选清单的真实信号——这一步是 AI 帮我把多个池子的原始数据汇总去重、交叉核查、对最强信号逐条事实核实,不是凭空生成趋势。

这一期两条主线都指向同一个母题:**AI 工具「能用」之后,第二波问题来了——可靠不可靠、划不划算、私有还是开源。** 第一条最戳独立开发者:过去一年大家用 AI「一把梭」(vibe coding)做小工具、小站爽到飞起,但安全债这周集中引爆了——Veracode 测过 100 多个模型,发现 **45% 的 AI 生成代码带 OWASP Top 10 漏洞**,且这个比例「vendor 天天说改进了」却纹丝不动;Georgia Tech 的 Vibe Security Radar 单月(2026-03)就追踪到 **35 个直接归因于 AI 编码工具的 CVE**,估计真实数是 5-10 倍;最出圈的案例是 Moltbook——一个创始人公开说「我没写一行代码」、纯靠 AI 搭起来的 AI 社交网,2026-01-28 上线,**3 天内**就被 Wiz 的研究员扒出暴露了整个生产数据库,含 150 万条 API token、3.5 万邮箱和私信。第二条是智谱 GLM-5.2 把开源权重模型往「打崩闭源利润」又推了一大步(下面细说)。下面 9 个领域的真实信号 + 26 个 SEO 长尾词,你大概能挑出 1-2 个能写一篇内容的 niche。

## 数据源 + 扫描方法(每期固定模块)

**本期实际跑通的源**:

- HackerNews Firebase API,top 50(含 Show HN)——本周技术圈信号主力
- 百度实时热搜 top 50(`top.baidu.com/board?tab=realtime`)——大陆真实信号源(本周几乎全是赛事 + 汛情)
- pytrends 跨 12 领域英文种子词(US,往前 7 天 rising):AI / SaaS / 副业 / 电商 / 健康 / 家居 / 游戏 / 教育 / 本地服务 / 海外营销 / 加密 / agentic AI——家居 / 园艺 / 本地服务 / 海外营销 / 加密 / 游戏 跑通,AI / SaaS / 副业 / 电商 / agentic 触发 429 限流
- **Reddit OAuth**:用应用级 OAuth(client_credentials)绕过匿名 JSON 的 403,搜了 4 个独立开发 / SaaS / 副业子版的「愿付费 / 求工具」短语——本周捞到「离线 / 非 AI / 自托管工具」这条线
- 跨领域 WebSearch:对本期最硬的两条(vibe coding 安全债、GLM 5.2)逐条做了事实核查,并核实了在家测基因的市场数据

**本期没跑通的盲区(数据为空 ≠ 没需求)**:

- Google 每日热搜 RSS(`trends.google.com/trending/rss?geo=US`):本周 **403 反爬**,拿不到当日 US trending,是本期新增盲区
- X 24h 累计(trends24.in):**403**;改用备用后拿到的也几乎全是世界杯 + Kalshi 预测市场 + Bezos,英语青年文化池子无可用 niche
- **Reddit request-type 过滤仍未上线**(承接 W26 说的 W27 计划):本期 Reddit 仍是「按相关性返回 + 混着『我做到 $Xk MRR』成功故事帖」,已人工筛出真需求,句式过滤下期继续做
- pytrends 中文种子词(zh):已知空(W24 实测 8 域 7 空),本期中文信号全靠百度
- Product Hunt:Cloudflare;微博 / 知乎 / 小红书:反爬未解

**判断准则(每期不变)**:

1. **viral 名人 / 赛事 / 突发新闻不是 niche**。本周百度前 50 是世界杯西班牙绝杀葡萄牙、C罗告别、湖北龙卷风、广西暴雨防汛——增长率惊人但 **24 小时到一周内归零**,做 SEO 站没意义。
2. **HN 高赞 ≠ 高搜索量**。本周「学编程仍然值得(101 票)」「拒绝把 AI 当默认执行引擎」是观点 / 情怀帖,搜索量低,适合写观点长文不适合做 SEO。
3. **被反爬挡住的源,数据为空 ≠ 没有需求**。本周缺 Google RSS + X 这两个池子,只代表工具链没够到。

## 国内 vs 国外:中文圈本周被赛事+汛情占满,唯一穿透两圈的是 GLM 5.2

本周这张对照表又回到了常态的「错位」——中文圈百度前 50 里,能建 SEO 站的真消费/理财信号几乎为零,大半是世界杯(西班牙补时绝杀葡萄牙、C罗最后一舞)、防汛(湖北龙卷风致 8 死、广西暴雨)、七七事变、中日地缘。**这些热度数字都在 300-800 万区间,但没有一个能撑起一篇半年后还有人搜的内容**。

- **大陆主流注意力本周被新闻彻底占满**:世界杯 + 汛情 + 历史纪念 + 地缘,是典型的「增长率极高、SEO 价值为零」组合。真正能穿透中文圈的 AI 硬信号只有一条——**GLM 5.2**,因为它是智谱(国产)开源、且中文独立开发者会实打实关心「能不能改个 base URL 把 Claude Code 后端换成 GLM 省钱」。这是本周中文圈唯一该抄的作业。
- **英文圈本周是「AI 工具化的第二波」一条主轴**:vibe coding 安全债、开源模型打崩利润、本地小模型下沉、离线/自托管工具、在家测基因——全部指向同一个母题,即 AI「能用」之后开始被追问**可靠不可靠(安全债)、划不划算(GLM 打价格)、私有还是自己掌握(本地/离线/自托管)**。做英文站沿这条主轴走,题材彼此串联、复用度高。
- **唯一中外都能落地的交叉点是「AI 写的代码/工具到底安不安全」**:它在英文圈是 vibe coding security 的技术话题,在中文圈是每个用 AI「一把梭」做小工具、小程序、小站的人的切身问题——**中文圈这个角度几乎空白**,是本周最值得先发的隐私/安全科普选题。

## 三个数据陷阱(每个对应一条「不要做」)

### 陷阱 1:增长率最高的,SEO 价值往往最低

本周百度热度最高的是「总书记鼓励我好好干」、西班牙绝杀葡萄牙、湖北龙卷风——瞬时搜索量极高,但**赛事 / 突发新闻 / 时政 / 灾害,过了这周就塌**。

**判断标准**:这个词 6 个月后还会有人搜吗?会(`vibe coding 安全风险`、`glm 5.2 本地部署`、`will a dehumidifier cool a room`、`在家全基因组测序费用`),做;不会(`西班牙绝杀葡萄牙`、`湖北龙卷风`),不做。

### 陷阱 2:HN 票数 ≠ 搜索量,要看「有没有商业意图长尾」

平时 HN 高赞经常只代表程序员社区在讨论,搜索量为零——比如本周「学编程仍然值得」101 票、「拒绝把 LLM 当默认执行引擎」,都是观点 / 情怀帖,适合写观点长文不适合做 SEO。但「vibe coding security」「GLM 5.2」「robot lawn mower」这种,autocomplete 里已经长出 `how to secure a vibe coded app`、`glm 5.2 vs claude`、`robot lawn mower without perimeter wire` 这类成型的商业 / 信息意图长尾,才真正值得进关键词矩阵。

**判断标准**:HN 单帖高赞 → 写一篇有观点的解读文;一个主题已经长出 "best / vs / how to / 是什么" 长尾 → 进 SEO 关键词矩阵。

### 陷阱 3:种子词决定你能看到什么

做 niche 调研最容易翻车的,是用一组**预设方向**的种子词去查趋势工具,误以为跑出来的就是「全网真实信号」。事实是种子词预先就在替你筛数据。

- **只用 AI 种子词就只能看见 AI 圈**:本周我强制跨了 12 个领域种子词,才在 AI 主线之外捞到「除湿机能不能降温」「无边界线割草机器人」「UGC 副业」这些跳出 AI 圈的季节 / 电商 / 副业机会。
- **Google Trends 在大陆不可用**,它跑出的「中文圈」是海外华人 + 港台新加坡,跟国内 14 亿搜索行为是两个池子。本期中文信号全靠百度——做中文站必须接百度 / 小红书。
- **每个数据源都有盲区**:本周 Google RSS + X 双双 403,只靠 HN(技术圈)+ 百度(大陆主流)+ pytrends(英文搜索)+ Reddit(独立开发)四个池子交叉。单一数据源 = 偏狭世界观。

**判断标准**:做新 niche 之前至少跨 3 个数据源验证。本周进 SEO 候选清单的词,我都在 HN / 百度 / autocomplete / pytrends / Reddit 至少 2-3 个池子里交叉看过,且对最硬的两条(vibe coding 安全债、GLM 5.2)做了 WebSearch 事实核查。
