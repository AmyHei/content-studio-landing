每周一更新的 niche 雷达。我每周扫 HackerNews 前 50 + 百度实时热搜 + pytrends 跨 12 领域英文种子词 + Reddit OAuth + Google/百度 autocomplete + 跨领域 WebSearch,用「不预设方向」的种子词**搜索整理**出本周值得加进 SEO 候选清单的真实信号——这一步是 AI 帮我把多个池子的原始数据汇总去重、交叉核查、对最强信号逐条事实核实,不是凭空生成趋势。

这一期的主线,是上一期主线的下一段。W27 我写的是 vibe coding 的**安全债**:你用 AI 一把梭做的东西可能不安全。这一期爆的是**成本债**:你用 AI 一把梭做东西的账单,可能比你想的贵一个数量级——而且这次不是独立开发者在抱怨,是微软和 Uber 用真金白银验出来的。**微软在 6 月 30 日(其财年末)前砍掉了内部大部分 Claude Code license**,让 Windows、Microsoft 365、Outlook、Teams、Surface 的工程师改用自家 GitHub Copilot CLI;公开报道给出的理由不是「不好用」,而是 Claude Code 按 token 计费、工程师用得太狠,费用提前几个月冲爆了年度 AI 预算。同一条线上,**Uber 的五千名工程师在四个月里烧光了 2026 全年 AI 预算**——人均每月 $150-250,重度用户 $500-2000,现在被封顶到每人每工具每月 $1500(彭博 6 月 2 日)。

于是一个新问题第一次有了买单的人:**你的 AI 编码开销到底花在哪、值不值、怎么管。** 这个 niche 现在几乎是空的,而验证它的是两家巨头的财务部门。下面 13 个真实信号 + 26 个 SEO 长尾词,你大概能挑出 1-2 个能写一篇内容的 niche。

## 数据源 + 扫描方法(每期固定模块)

**本期实际跑通的源**:

- HackerNews Firebase API,top 50(含 Show HN)——本周技术圈信号主力
- 百度实时热搜 top 50(`top.baidu.com/board?tab=realtime`)——大陆真实信号源
- Google 每日热搜 RSS(`trends.google.com/trending/rss?geo=US`)——**本周恢复**(W27 是 403),但内容全是 MLB / NBA 夏季联赛 / WWE,无可用 niche
- pytrends 跨 12 领域英文种子词(US,近 3 个月 rising):AI / SaaS / 副业 / 电商 / 健康 / 家居 / 游戏 / 教育 / 本地服务 / 海外营销 / 加密 / agentic AI——多数跑通,家居 / 加密 触发 429 限流
- **Reddit OAuth + 本期新上的 request-type 过滤**(见下)——本周终于捞到干净的真需求
- 跨领域 WebSearch:对本期最硬的六条(微软砍 Claude Code、Uber 烧预算、Medicare GLP-1 Bridge、Samsung Health、t.me 停域、Hermes / Koji)逐条做了事实核查

**本期修好的一个源:Reddit 的「成功故事帖」噪音**

W26 和 W27 都记着一句「Reddit 搜索按相关性返回,混着一堆『我做到 $Xk MRR』的成功故事帖,下期加过滤」。**本期做了**:根因是 Reddit 搜索按**相关性**排序,一篇标题叫「我的 SaaS 做到 $2k MRR」的帖子,正文里聊到付费用户,于是被 `willing to pay` 这个查询高分召回——但它根本不是一个需求。所以过滤不能加在查询上,得加在**标题**上:只保留标题真的在**提问 / 求工具 / 说缺什么**的帖子,并对「$X MRR」「我做了个」「我的第一个付费用户」这类炫耀句式一票否决。

效果:本周同一批查询,**196 条 → 67 条**,活下来的基本都是真问题。本期 Reddit 的两条信号(印一万本手册该信哪个短链、小商家被无障碍诉讼盯上)就是这么捞出来的——**在过滤之前,它们被压在几十条 MRR 炫耀帖底下,前两期都没看见**。

**本期没跑通的盲区(数据为空 ≠ 没需求)**:

- X 24h 累计(trends24.in):抓到了,但**整池零可用**——前 60 个趋势全是名人 / 影视 / 赛事(Sam Neill、侏罗纪公园、本垒打大赛、RHOA)。这不是技术故障,是这个池子本周确实没有 niche
- pytrends 中文种子词(zh):8 个领域跑完 **7 个空**、1 个返回世界杯——**这是已知的结构性问题**:Google Trends 在大陆不可用,它的「中文圈」是海外华人 + 港台新加坡,样本量小。中文信号全靠百度
- Product Hunt:Cloudflare;微博 / 知乎 / 小红书:反爬未解

**判断准则(每期不变)**:

1. **viral 名人 / 赛事 / 突发新闻不是 niche**。本周 X 整池是侏罗纪公园和本垒打大赛、百度前 50 是世界杯半决赛和台风巴威——增长率惊人但 **24 小时到一周内归零**。
2. **HN 高赞 ≠ 高搜索量**。本周「GhostLock:潜伏 15 年的 Linux UAF 漏洞」393 票、「摩斯电码的绝对魔力」116 票,前者值得写但搜索窗口极短,后者纯情怀。
3. **被反爬挡住、或本周为空的源,不代表没有需求**。中文圈 pytrends 连续多期为空,是工具够不到,不是需求不存在。

## 国内 vs 国外:本周唯一同频的领域是「健康」,但两边推的方向相反

本周这张对照表最有意思的地方,不是错位,而是**同一周中美都在健康这件事上出手,但姿势完全相反**。

- **美国是「掏钱」**:CMS 的 Medicare GLP-1 Bridge 在 7 月 1 日正式开跑,用每月 $50 的自付把减重药塞进医保参保人手里——这是**药物路线**,直接补贴到处方。
- **中国是「管人」**:国务院印发《国民健康「十五五」规划》,叠加正在收官的体重管理三年行动、京东健康的减重大赛——这是**行为干预 / 公共卫生路线**,搞的是打卡、赛事、体脂秤。
- **而三星在同一周干了第三件事**:拿「不同意训 AI 就删光你的健康数据」逼用户签字。于是「健康数据」这个词在本周同时被**医保、公共卫生、AI 训练**三方拉扯——这是本周最值得写的跨界选题,而且中英两圈都能落。

除此之外,中文圈依然是老样子:百度前 50 大半被世界杯半决赛、伊朗战事、台风巴威、沈阳暴雨占满,**热度 400-790 万但没有一个能撑起半年后还有人搜的内容**。唯一的例外是「超强厄尔尼诺」——它的价值不在这周,在秋天。

## 三个数据陷阱(每个对应一条「不要做」)

### 陷阱 1:增长率最高的,SEO 价值往往最低

本周 X(trends24)前 60 个趋势,**没有一个是 niche**——Sam Neill、侏罗纪公园、本垒打大赛、RHOA、Rihanna。百度那边是世界杯半决赛、伊朗战事、台风巴威。这些词的瞬时搜索量高到吓人,但**过了这周就塌**。

**判断标准**:这个词 6 个月后还会有人搜吗?会(`claude code 成本怎么算`、`medicare glp-1 bridge eligibility`、`自托管短链服务`、`ai 家教 靠谱吗`),做;不会(`侏罗纪公园`、`台风巴威`、`法国vs西班牙`),不做。

### 陷阱 2:「按相关性返回」会把真需求埋掉——本周终于把它挖了出来

这一条是本期方法论上的真收获,值得单独说。

Reddit 搜索按**相关性**排序,不按标题匹配。所以你搜 `willing to pay`,排在最前面的往往是「**我的 SaaS 做到 $2k MRR,复盘一下**」——因为它正文里大谈付费用户,语义上高度相关。**但它不是一个需求,它是一次炫耀。** 前两期我都只能靠人工从上百条里挑,还两次在周报里写「下期加过滤」。

本期加了:过滤不加在查询上,加在**标题**上——只留标题真的在提问 / 求工具 / 说缺什么的帖子,并对「$X MRR」「我做了个」「我的第一个付费用户」「这是我学到的」这类炫耀句式一票否决(哪怕它伪装成问号结尾)。**196 条 → 67 条**,而本期 Reddit 贡献的两条信号(短链十年后还在不在、小商家被无障碍起诉)**之前一直被压在 MRR 炫耀帖底下,两期都没看见**。

**判断标准**:任何按「相关性 / 热度」返回的数据源(Reddit、微博、知乎、小红书),召回和意图是两码事。**先问「这条数据是需求还是表演」,再决定要不要信它。**

### 陷阱 3:商业价值高 ≠ 你能进得去

本周的「网站无障碍诉讼」是一个完美的反面教材:痛点真实(有人真被起诉了)、商业意图极强(被告愿意马上花钱)、受众明确(小商家)——看起来是完美 niche。

但我顺手看了一眼它的 SERP:**前排全是无障碍厂商(accessiBe 之流)和律所的内容机器**,清一色 "ADA Website Lawsuits 2026""ADA Compliance Checklist"。这和 W25 那条「AI infra 新词四个月内被厂商 Definitive Guide 填满」是同一个病:**当一个词能直接卖出去一个产品或一份服务时,卖那个产品的人早就把 SERP 铺满了。**

**判断标准**:一个词越容易变现,它的 SERP 越可能已经被卖家占领。**动手前必须 live 跑 `/SERP分析`,不要只看 autocomplete 说「有词」就上**。反过来,本周第一名(AI 编码成本治理)之所以值钱,恰恰因为它现在还**没有**一个成熟产品在卖——SERP 是空的,而痛点已经被微软和 Uber 验证了。
